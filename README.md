
# NSFFESTIVAL

NSFFESTIVAL est un projet open source permettant de gérer un festival. Il s'agit d'une application web avec une interface utilisateur (front-end) développée en **React** et un back-end en **Express**. Le projet inclut également une partie administrative pour gérer les artistes, les news, le planning, et plus encore.

## Installation

### Installation du Front-End

Pour installer et lancer la partie front-end du projet (React) :

```bash
cd nsf
npm install
npm run build
```

Pour démarrer le serveur de développement :

```bash
npm run dev
```

Vous pouvez également utiliser la commande suivante pour démarrer l'application en production :

```bash
npm start
```

> **Remarque** : Ces instructions sont valables aussi bien pour Windows que pour Linux.

### Installation du Back-End

Pour installer et lancer la partie back-end du projet (Express) :

```bash
cd server
npm install
npm run dev
```

Pour exécuter les tests :

```bash
npm test
```

### Lancer le projet complet

Pour lancer l'ensemble du projet (front-end et back-end) depuis la racine du projet :

```bash
node server/server.js
```

## Usage

Une fois le projet lancé, vous pouvez accéder à l'interface utilisateur pour :
- **Visiter le site** : Parcourir les pages du festival.
- **Découvrir les artistes** : Voir les détails des artistes participants.
- **Utiliser la carte interactive** : Explorer les différents lieux du festival.
- **Se connecter** : Accéder à votre compte personnel.
- **Accéder à votre billet** : Afficher et gérer votre billet pour l'événement.

En tant qu'administrateur, vous pouvez également :
- **Se connecter** : Accéder à l'interface d'administration.
- **Gérer les données** : Ajouter, modifier ou supprimer des informations du festival.
- **Ajouter, modifier ou supprimer des artistes** : Gérer la liste des artistes participant au festival.
- **Ajouter, modifier ou supprimer des news** : Gérer les actualités du festival.
- **Gérer le planning** : Organiser le calendrier des événements.
- **Gérer les messages urgents** : Envoyer et gérer des annonces importantes.
